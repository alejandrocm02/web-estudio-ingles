Privacidad por diseño

P/ Política de privacidad

Qué información utiliza StudyEnglish y dónde permanece.

Resumen claro

StudyEnglish no pide registro ni recopila directamente tus datos personales.

La web no tiene formularios, cuentas, publicidad, analítica propia ni sistemas de perfilado. El tema visual y el progreso de estudio se guardan localmente en tu navegador.

Vigente desde el 27 de julio de 2026
Responsable

Quién gestiona el sitio

StudyEnglish es un proyecto educativo personal gestionado públicamente por @alejandrocm02. Puedes comunicar incidencias técnicas mediante el repositorio del proyecto. No publiques allí datos personales o información sensible.

Datos locales

Progreso y preferencias

StudyEnglish usa el almacenamiento local del navegador, una función técnica similar a la memoria interna de una aplicación, para conservar:

  • theme: la preferencia de tema claro u oscuro.
  • studyProgressV1: ejercicios completados, mejores resultados, vocabulario marcado, audios y lecturas realizados y racha de estudio.

Esta información permanece en tu dispositivo y el código de StudyEnglish no la envía al responsable del proyecto ni a una base de datos. Puedes eliminarla borrando los datos del sitio desde la configuración de tu navegador.

Alojamiento

Datos técnicos tratados por GitHub Pages

La web está alojada en GitHub Pages, servicio prestado por GitHub. Según su documentación, GitHub registra la dirección IP de las visitas por motivos de seguridad, incluso cuando la persona no ha iniciado sesión. Ese tratamiento depende de GitHub y se rige por su propia política.

  • Información de GitHub Pages sobre recopilación de datos
  • Declaración general de privacidad de GitHub
Cookies y terceros

Sin publicidad ni seguimiento

StudyEnglish no instala cookies publicitarias o analíticas y no integra píxeles de seguimiento. Las tipografías se resuelven de forma local en el dispositivo, sin solicitar archivos a Google Fonts.

Los enlaces a páginas externas solo se abren cuando decides pulsarlos. Desde ese momento se aplican las políticas del sitio de destino.

Base y conservación

Por qué se usa el almacenamiento local

El almacenamiento local es estrictamente funcional: permite recordar una preferencia solicitada y mostrar el avance educativo. Se conserva hasta que lo elimines, restablezcas el navegador o el sitio cambie la versión de almacenamiento.

StudyEnglish no realiza decisiones automatizadas con efectos jurídicos, no crea perfiles comerciales y no vende ni cede datos.

Derechos y cambios

Control sobre la información

Como el responsable de StudyEnglish no recibe el progreso guardado localmente, puedes ejercer el control directamente desde tu navegador: consultar, borrar o bloquear el almacenamiento del sitio. Para datos técnicos tratados por GitHub, consulta sus canales de privacidad y ejercicio de derechos.

Esta política se revisará si se incorporan formularios, cuentas, analítica, publicidad, nuevas integraciones externas o cualquier tratamiento adicional.

Importante: si en el futuro StudyEnglish solicita información personal, se mostrará una información específica antes de recogerla y se actualizará esta política.
