Privacidad por diseño

P/ Política de privacidad

Qué información utiliza StudyEnglish y dónde permanece.

Resumen claro

Tu cuenta y tu progreso permanecen en tu dispositivo.

StudyEnglish permite crear perfiles locales, pero no envía el usuario, la contraseña ni el progreso a una base de datos. La web no incorpora publicidad, analítica propia ni sistemas de perfilado.

Vigente desde el 28 de julio de 2026
Responsable

Quién gestiona el sitio

StudyEnglish es un proyecto educativo personal gestionado públicamente por @alejandrocm02. Puedes comunicar incidencias técnicas mediante el repositorio del proyecto. No publiques allí datos personales o información sensible.

Datos locales

Progreso y preferencias

StudyEnglish usa el almacenamiento local del navegador, una función técnica similar a la memoria interna de una aplicación, para conservar:

  • theme: la preferencia de tema claro u oscuro.
  • studyEnglishAccountsV1: nombre de usuario, identificador local, fecha de creación, sal aleatoria y resultado derivado de la contraseña.
  • studyEnglishSessionV1: identificador de la cuenta local que mantiene la sesión activa.
  • studyProgressV1: ejercicios completados, mejores resultados, vocabulario marcado, audios, lecturas, respuestas y racha de estudio, separados por cuenta.

La contraseña no se conserva en texto legible: el navegador deriva una huella mediante PBKDF2 con SHA-256, una sal aleatoria y múltiples iteraciones. Aun así, se trata de una cuenta local, no de una cuenta sincronizada en la nube.

Esta información permanece en tu dispositivo y el código de StudyEnglish no la envía al responsable del proyecto ni a una base de datos. Puedes eliminar una cuenta y su progreso desde el panel de usuario o borrar todos los datos del sitio desde la configuración del navegador.

Alojamiento

Datos técnicos tratados por GitHub Pages

La web está alojada en GitHub Pages, servicio prestado por GitHub. Según su documentación, GitHub registra la dirección IP de las visitas por motivos de seguridad, incluso cuando la persona no ha iniciado sesión. Ese tratamiento depende de GitHub y se rige por su propia política.

  • Información de GitHub Pages sobre recopilación de datos
  • Declaración general de privacidad de GitHub
Cookies y terceros

Sin publicidad ni seguimiento

StudyEnglish no instala cookies publicitarias o analíticas y no integra píxeles de seguimiento. Las tipografías se resuelven de forma local en el dispositivo, sin solicitar archivos a Google Fonts.

Los enlaces a páginas externas solo se abren cuando decides pulsarlos. Desde ese momento se aplican las políticas del sitio de destino.

Base y conservación

Por qué se usa el almacenamiento local

El almacenamiento local es estrictamente funcional: permite mantener una sesión solicitada, separar perfiles, recordar preferencias y mostrar el avance educativo. Se conserva hasta que elimines la cuenta, borres los datos del sitio, restablezcas el navegador o el sitio cambie la versión de almacenamiento.

StudyEnglish no realiza decisiones automatizadas con efectos jurídicos, no crea perfiles comerciales y no vende ni cede datos.

Derechos y cambios

Control sobre la información

Como el responsable de StudyEnglish no recibe las cuentas ni el progreso local, puedes ejercer el control directamente desde el panel de usuario y desde tu navegador: consultar, eliminar o bloquear el almacenamiento del sitio. Para datos técnicos tratados por GitHub, consulta sus canales de privacidad y ejercicio de derechos.

Esta política se revisará antes de incorporar sincronización en la nube, analítica, publicidad, nuevas integraciones externas o cualquier tratamiento adicional.

Importante: una cuenta local no puede recuperarse desde otro dispositivo. Si borras los datos del navegador o eliminas la cuenta, su progreso también se elimina.
